Third-party 3D assets used by Football Legacy (all CC BY 4.0 — http://creativecommons.org/licenses/by/4.0/)

lib/player.glb — footballer model and run animation:
  "Slow Run" by arow102 — https://sketchfab.com/3d-models/slow-run-011d9a589311491390c3b7a8e4ad1149
  plus the idle animation retargeted from
  "Standing Man" by zhuoyi0904 — https://sketchfab.com/3d-models/standing-man-8401da7cb2564fc08681836cbeff39bc
  Changes: mesh welded and simplified, unused UV sets removed, translation tracks removed,
  idle clip retargeted onto the same skeleton. Kit, skin, hair and boot colours are repainted in-game.

lib/stadium.glb — stadium:
  "Vinh Stadium" by NGUYENNGHIAKK — https://sketchfab.com/3d-models/vinh-stadium-32f76b7be2f24eb4a5d1e827f2285c50
  Changes: welded, simplified, merged by material, textures resized to 1024px, quantized.
  In-game the original pitch surface is replaced and an animated crowd is placed on the tiers.

lib/player.glb animation clips "dribble", "strike" and "spin" — Mixamo animations (Dribble, Strike Forward Jog,
Soccer Spin) supplied by the project owner, retargeted onto the player skeleton with root motion removed.

lib/grass_detail.jpg, lib/crowd_a.jpg, lib/crowd_b.jpg — AI-generated for this project on RunComfy
(FLUX.2 Klein 9B for grass, Z-Image Turbo for crowds), then processed (detail extraction, seam blending).
lib/RoomEnvironment.js — three.js r170 example (MIT), import path rewritten.

lib/player_hero.glb — your player's model (Step 1 of the model upgrade):
  "3D Rigged Cristiano Ronaldo Al Nassr" by Lean_Lo1786 — https://sketchfab.com/3d-models/3d-rigged-cristiano-ronaldo-al-nassr-1424fba6eedb4d54a2621284f149a96c
  CC BY 4.0. Changes: spec-gloss materials converted to metal/rough, textures resized and WebP-compressed,
  Valve-biped bones renamed to Mixamo names, kit repainted in-game per team.
  Animation clips: Mixamo animations supplied by the project owner (Offensive Idle, Jog Forward, Jog Forward/
  Backward Diagonal, Jog Strafe Left (+ mirrored right), Dribble, Strike Forward Jog, Soccer Penalty Kick,
  Soccer Pass, Soccer Header, Soccer Spin, Throw In, Soccer Trip, Getting Up, Front Flip, Goalkeeper Diving
  Save, Goalkeeper Sidestep), retargeted from the Mixamo skeleton onto this rig, root motion removed.
